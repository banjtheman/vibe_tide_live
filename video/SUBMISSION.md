# Competition upload kit

## YouTube title

**VibeTide Live — Build Playable Worlds with WebMCP**

## YouTube description

VibeTide Live is a colorful browser platformer and instant level maker where
people and agents build the same playable world together.

Using WebMCP, the webpage exposes ten structured tools that let a visiting agent
inspect, create, patch, validate, playtest, repair, undo, restyle, and share a
level. There is no chatbot bolted onto the game: the game itself is the tool.

- Play: https://vibetide-live.banjtheman.chatgpt.site/
- Source: https://github.com/banjtheman/vibe_tide_live
- WebMCP implementation: https://github.com/banjtheman/vibe_tide_live/blob/main/docs/WEBMCP.md

Built for the OpenAI WebMCP Challenge. Gameplay and page-tool effects shown in
the video were captured from the running production app and its real tool
handlers.

#WebMCP #OpenAI #IndieGame #GameDev

## Suggested Devpost summary

VibeTide Live turns plain-language level ideas into playable 2D platformer
routes. A player can run and jump as an animated headphone-wearing otter, paint
tiles by hand, choose from ten ocean worlds, playtest hazards and three enemy
families, then share the exact level as one compact URL. Through WebMCP, an agent
can use the same state as the visual editor: it can generate a route, validate
reachability, read structured death clusters, make a targeted repair, and hand
back a ready-to-play link.

## Upload checklist

- Upload `out/vibetide-webmcp-challenge.mp4` as the public YouTube demo.
- Upload `out/vibetide-youtube-thumbnail.jpg` as the custom thumbnail.
- Upload `out/vibetide-webmcp-challenge.srt` as the English subtitle track.
- Confirm YouTube reports a runtime of approximately 2:16, safely below the
  challenge's strict three-minute limit.
- Put the live site and public GitHub repository in the first lines of the
  description.
- Watch the uploaded 1080p version once before placing its public URL in
  Devpost.

The official challenge requires a public YouTube demo with audio that clearly
shows the functioning project and explains how WebMCP is used. See the
[challenge page](https://openai.com/webmcp-challenge/) and
[Devpost rules](https://webmcp.devpost.com/rules).
